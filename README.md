# MAFAR-BARMM Infrastructure Monitoring System

## About the Project
A web-based system developed to support the monitoring, documentation, and reporting of infrastructure projects implemented under the Ministry of Agriculture, Fisheries and Agrarian Reform (MAFAR), BARMM.

## Features
- Infrastructure Project Management
- Project Monitoring and Evaluation
- Project Status Tracking
- GIS Mapping and Geotagging
- Photo Documentation
- Accomplishment Monitoring
- Monitoring Reports
- Data Visualization
